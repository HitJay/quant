## 一、A股量化生态全景

### 1.1 与美股量化的关键差异

| 维度 | A股 | 美股 |
|------|-----|------|
| 做空机制 | 仅融券（门槛高、券源少） | 全面做空 |
| T+0 | 不可（T+1） | 可 |
| 涨跌停 | ±10%（科创/创业 ±20%） | 无 |
| 数据获取 | 免费源多但质量参差 | 免费源有限但量化成熟 |
| 手续费 | 印花税0.05%+佣金 | 极低/零佣金 |
| 分红 | 分红后除权除息，持股1年以上免税 | 需缴税 |

**核心结论：A股量化天然更适合长线。** T+1和做空限制使得高频/日内策略空间极小，而价值因子、动量因子、红利策略等中长期策略反而是主场。

### 1.2 你的投资范围分析

```
┌─────────────────────────────────────────────────┐
│           你的可投标的                             │
├───────────────┬──────────────┬──────────────────┤
│   大盘个股     │    ETF      │    场外基金        │
├───────────────┼──────────────┼──────────────────┤
│ 沪深300成分股  │ 宽基ETF     │ 股票型基金        │
│ 中证500成分股  │ 行业ETF     │ 混合型基金        │
│ 上证50成分股   │ 策略ETF     │ 指数基金          │
│               │ 跨境ETF     │ 债券基金          │
│               │ 债券ETF     │ QDII             │
│               │ 商品ETF     │                  │
└───────────────┴──────────────┴──────────────────┘
```

**建议的量化优先级：ETF > 大盘个股 > 场外基金**

原因：
- ETF：流动性好、数据完整、策略回测最直接、无选股偏差
- 大盘个股：需处理停牌、ST、财务造假等A股特有问题
- 场外基金：T+2确认、净值日频数据、适合定投/配置优化而非主动量化

### 2.2 推荐方案

```
首选：akshare（免费，覆盖面广）
  ├── 股票：日线/周线/月线、财务数据、资金流向
  ├── ETF：净值/行情/规模/份额变动
  ├── 基金：净值历史/持仓/基金经理
  ├── 指数：成分股/权重/估值
  └── 宏观：GDP/CPI/PMI/利率

进阶：akshare + tushare（互补）
  └── tushare的财务数据质量更高，akshare覆盖面更广
```

### 2.3 场外基金的特别注意

场外基金（你提到的场外基金）数据特点：
- 净值数据：日频，T日净值T+1公布
- 申赎：T+1~T+3确认
- 因此：**场外基金适合月度/季度级别的配置优化**，不适合高频轮动

## 三、长线量化策略体系

### 3.1 策略分类全景

```
长线量化策略
├── 选股策略
│   ├── 多因子选股（价值+质量+动量+低波）

│   ├── 均线系统（周线/月线级别）
│   ├── 宏观指标（PMI/社融/CPI）
│   └── 市场情绪（两融/北向资金/换手率）
│
├── ETF轮动
│   ├── 行业轮动（动量+基本面）
```

### 3.2 A股验证过的长线有效因子

按重要性排序：

#### 第一梯队（强有效）
1. **价值因子**：PE、PB、PS——A股价值溢价比美股更显著
2. **规模因子**：小盘股长期超额收益（但有阶段性反转）
3. **红利因子**：股息率——A股高股息策略长期跑赢
4. **动量因子**：过去6-12个月收益（中期动量在A股有效）

#### 第二梯队（有效但有噪音）
5. **质量因子**：ROE、毛利率、现金流/利润比
6. **低波动因子**：低beta/低波动异常在A股存在
7. **成长因子**：营收增速、利润增速（A股成长股波动大）

#### 第三梯队（辅助）
8. **换手率因子**：机构 vs 散户行为差异
9. **分析师预期因子**：一致预期变化
10. **北向资金因子**：外资持续流入信号

### 3.3 实战组合策略推荐

**策略A：股债性价比 + ETF轮动（最推荐起点）**

```
核心逻辑：
  当沪深300股息率 > 10年国债收益率 → 重仓权益ETF
  当沪深300股息率 < 10年国债收益率 + 2% → 防御为主
  中间区域 → 均衡配置

标的池：
  权益：510300（沪深300ETF）、510500（中证500ETF）、510880（红利ETF）
  防御：511010（国债ETF）、511990（华宝添益）
  增厚：513100（纳指ETF）、159920（恒生ETF）

调仓频率：月度或季度
```

**策略B：多因子选股 + 定期再平衡**

```
选股池：沪深300 + 中证500
因子：价值(30%) + 动量(25%) + 质量(20%) + 低波(15%) + 红利(10%)
持仓：20-30只
调仓：季度（A股换手成本高，频繁调仓不利长线）
止损：个股基本面恶化时被动剔除
```

**策略C：大类资产全天候**

```
配置目标（参考桥水全天候，A股化改造）：
  30% A股（沪深300+中证500+创业板各1/3）
  15% 海外权益（纳指+恒生各半）
  40% 债券（利率债+信用债+可转债）
  10% 商品（黄金ETF+豆粕ETF）
  5%  现金

再平衡：年度或偏离超5%时触发
```

**策略D：红利+成长双轮驱动**

```
核心：高股息策略作为底仓 + 成长因子做增强

底仓（60%）：红利ETF(510880) + 中证红利低波指数
  → 年化股息4-6% + 资产增值 + 股息再投资复利

增强（40%）：行业轮动ETF
```

## 六、关键风险与A股陷阱

### 6.1 A股特有坑

1. **幸存者偏差**：回测只能用现在存在的股票——退市股被排除会高估收益
   → 解决：使用指数成分股历史列表

2. **停牌处理**：停牌股在回测中如何处理？
   → 解决：标记停牌、不允许买入、允许卖出（如果能卖）

3. **财务数据滞后**：A股年报4月底前出，一季报4月底，中报8月底，三季报10月底
   → 解决：回测时必须使用公告日期而非报告期日期

4. **ST/\*ST处理**：退市风险警示股
   → 解决：直接过滤，不纳入选股池

5. **打新收益污染**：持仓股票中签新股带来的额外收益
   → 解决：回测去除非理性打新收益

6. **分红再投资**：A股分红后除权，需精确计算复权价格
   → 解决：统一使用后复权价格

### 6.2 长线策略的独特风险

1. **参数过拟合**：用10年数据调出的参数，未来10年未必有效
   → 解决：少参数、逻辑驱动而非数据挖掘

2. **风格漂移**：价值因子可能连续3年跑输成长
   → 解决：分散因子、给自己定纪律

3. **宏观突变**：政策变化（如2021年教育双减）可能摧毁行业逻辑
   → 解决：分散行业、加入宏观过滤

4. **流动性陷阱**：小盘股看似回测好，实盘无法成交
   → 解决：限制日均成交额门槛

## 七、我的最终建议

### 研发路径优先级排序

```
第一优先：ETF轮动 + 股债性价比（1个月内可出原型）
  └── 标的简单、数据干净、策略逻辑清晰
  └── 最符合你的"长线操作"定位

第二优先：红利策略 + 多因子选股（2-3个月）
  └── A股红利策略长期有效
  └── 多因子选股是量化基本功

第三优先：大类资产配置（3-4个月）
  └── 加入场外基金做战术配置
  └── 跨国别/跨资产分散

长期迭代：
  └── 持续优化因子
  └── 加入宏观择时
  └── 实盘监控体系
```

### 一句话总结

> **A股量化，从ETF轮动开始，以多因子选股深化，用资产配置收官。**
> **长线的核心不是预测，是：分散 + 纪律 + 复利。**
