# 定投场外热门基金 vs 场内买股票 — 胜率量化深度研究方案

> **日期**: 2026-06-10
> **目标**: 用可复现的历史数据回答散户最关心的问题——"无脑定投场外热门基金，胜率到底有多高？真的比自己场内买股票强吗？"
> **核心张力**: 散户两种最典型的入场方式——(A) 定投明星/热门主动基金；(B) 自己在场内挑热门股票。到底哪个胜率高、谁的"翻车"风险大。

## 1. 研究问题（三问）

1. **方法之争**: 同一个标的，"定投" vs "一次性梭哈"，谁的胜率高？代价是什么？
2. **标的之争**: 同样定投/同样一次性，"场外热门基金" vs "场内个股"，胜率与尾部风险差多少？
3. **追热门**: 在基金"最火"(近一年大涨)时入场，会怎样？定投能不能救追高？

## 3. 方法（滚动起点回测）

对每个标的、每个可行起点月 t0、每个持有期 H：

- **一次性**: `ret = S[t0+H]/S[t0] − 1`
- **定投**: 在 t0..t0+H−1 共 H 个月末各投 1 份，在 t0+H 估值；`ret = S[t0+H]·mean(1/S[buy]) − 1`

持有期 H ∈ {1, 2, 3, 5} 年。把同组(基金/个股)所有 (标的, t0) 结果合并统计：

- **胜率** = P(ret>0)
- **中位数 / P10 / P90 / 均值**
- **尾部风险** = P(ret<−30%)、P(ret<−50%)、最差情形

输出 4 组对照：`基金定投 / 基金一次性 / 个股定投 / 个股一次性`，外加 `沪深300定投` 基准。

### 3.x 追热门子实验
对基金，把起点限定在"近一年涨幅处于该基金历史前 1/3"（=最火/最容易被追的时刻），比较：
- 高位一次性买入 3 年胜率
- 高位起定投 3 年胜率 → 量化"定投救追高"的幅度。

---

## 4. 预期发现（待数据填充，诚实呈现）

1. 定投基金长期胜率显著高于个股（尤其 3-5 年）；个股"腰斩"概率远高于基金。
2. 定投 vs 一次性：定投提高胜率、压低波动，但**牛市里一次性收益更高**——定投买的是"安心+胜率"，不是收益最大化。
3. 即便追在热门高点，定投也能把胜率从 a% 拉到 b%。
4. 无脑定投沪深300 与主动热门基金的对比（谁更强，可能反常识）。
