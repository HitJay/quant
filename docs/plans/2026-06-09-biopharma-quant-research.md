# 创新药/生物医药 量化深度研究方案

> **日期**: 2026-06-09
> **目标**: 把"做药的人"的产业认知 + 量化信号结合, 系统研究医药板块的择时、轮动与抄底, 回答"集采压制多年、出海逻辑兴起的医药, 现在/未来怎么投"。
> **差异化护城河**: 作者是药物发现计算科学家, 能读懂管线/临床/BD交易价值——这是绝大多数财经量化账号缺失的领域 edge。

| 维度 | 判断 |

### 首看分析已验证的 4 个反常识发现 (纯价格数据, 可复现)

1. **政策是医药最大的择时变量**: 2018集采 **-33%** → 2019-21大牛 **+133%** → 2021-24深熊 **-60%**。
2. **"买医药 ≠ 买创新药出海"**: 2024-09反转后宽基医药仅 **+15%**, 跑输沪深300 **36%**——出海行情高度集中在少数真出海标的, 被宽基ETF稀释。
3. **动量轮动在医药内部失效**: 子板块追动量 2020-06起 **-75%**, 远差于等权(-62%)和沪深300(+24%)。
4. **当前-27%回撤是历史上胜率最低的尴尬区间**: 持有1年胜率仅44%; 真正的黄金坑是跌透(≤-40%, 胜率88%)。

> 这些发现既诚实又差异化, 天然适合做"破除惯性认知"的付费内容。

## 四个切入角度 (按"差异化 × 可落地"排序)

### 角度 A — 出海/License-out 事件驱动 ⭐ 头条 (deep-research skill 主战场)

**问题**: 重大 BD/出海公告前后, 相关个股/板块的超额收益? 能否提前识别?

**为什么用 deep-research skill**: 需要多源交叉验证(BD交易条款、临床背景、市场反应、政策环境), 正是该 skill(SCOPE→PLAN→RETRIEVE→TRIANGULATE→SYNTHESIZE→CRITIQUE→PACKAGE, 带引用追踪)的用武之地。

**事件清单 (待 RETRIEVE 阶段补全 + 引用)**:
- 标志性 BD: 百利天恒/BMS、科伦博泰/默沙东、信达、康方(PD-1/VEGF双抗)、恒瑞海外授权…
- 催化剂类型: 首付款规模、里程碑总额、合作方质量、适应症/靶点稀缺性
- 量化: 公告日 ±N 日累计超额收益(CAR)、按交易规模/靶点分层

**领域增益**: 作者能判断哪些 deal 是真利好(靶点稀缺/数据超越标准)vs 蹭热点。

### 角度 B — 医药政策底择时 ⭐ 量化可行性最高

**问题**: 集采/医保谈判节点对板块的冲击规律? 能否量化"政策底"?

**信号清单**:

| # | 信号 | 逻辑 | 优先级 |
|---|---|---|---|
| P1 | 集采事件窗口 | 集采落地前杀跌/后修复的统计 | ⭐⭐⭐ |
| P2 | 回撤分档抄底 | 距高点回撤 → 1年前向胜率(已验证U型) | ⭐⭐⭐ |
| P3 | 估值分位 | 医药PE/PB历史分位择时 | ⭐⭐⭐ |
| P4 | 政策利空钝化 | 利空出尽信号(成交缩量+企稳) | ⭐⭐ |

### 角度 C — 子板块轮动

**问题**: 创新药/CXO/器械/生物医药 谁领涨谁补跌? 轮动是否有效?

- 已验证: 单纯动量轮动**失效**(-75%)。需研究: 相对强弱反转、基本面轮动(景气度)、政策受益方向。
- 价值点: "为什么医药里追涨杀跌是灾难"本身就是好内容。

### 角度 D — 管线价值 vs 市值 (作者本行, 数据需手工)

**问题**: 用临床成功率 × 峰值销售给管线估值, 找市值低估标的。

- 最专业但数据密集(需管线库), 列为远期 Phase。
