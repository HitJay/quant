## 二、模块详细设计

### Module 1: `data/` — 数据层

**职责：从AKShare获取数据、清洗、本地缓存**

```
src/quant/data/
├── __init__.py
├── config.py          # 数据配置：缓存路径、默认日期范围
├── fetcher.py          # 数据获取统一入口
├── cleaner.py          # 数据清洗：复权、停牌标记、缺失值处理
└── cache.py            # 本地缓存：Parquet格式，增量更新
```

| 类/函数 | 说明 |
|----------|------|
| `DataConfig` | 缓存目录、默认起止日期 |
| `Fetcher` | 统一入口，根据asset_type路由到具体fetcher |
| `StockFetcher.fetch_daily(symbols, start, end)` | A股日线（后复权） |
| `ETFFetcher.fetch_daily(symbols, start, end)` | ETF日线+净值 |
| `CBFetcher.fetch_daily(symbols, start, end)` | 可转债日线 |
| `FundFetcher.fetch_nav(symbols, start, end)` | 场外基金净值 |
| `MacroFetcher.fetch_yield_curve()` | 国债收益率曲线 |
| `MacroFetcher.fetch_index_pe(index)` | 指数PE/PB历史 |
| `Cleaner.align_dates(df)` | 日期对齐 |
| `Cleaner.mark_suspended(df)` | 标记停牌日 |
| `Cleaner.fill_missing(df, method)` | 缺失值填充 |
| `Cache.load(cache_key)` / `Cache.save(data, key)` | Parquet缓存读写 |

**关键设计决策：**
- 所有价格统一使用**后复权**
- 缓存key格式：`{asset_type}/{symbol}/daily.parquet`
- 增量更新：只拉取本地缺失的日期段

### Module 3: `factors/` — 因子库

**职责：从原始数据计算各类因子**

```
src/quant/factors/
├── __init__.py
├── base.py             # 因子基类 + Factor Registry
├── stock/              # 股票因子
│   ├── __init__.py
│   ├── value.py        # PE/PB/PS/股息率
│   ├── momentum.py     # 1/3/6/12月动量
│   ├── quality.py      # ROE/毛利率/净利率
│   ├── volatility.py   # 波动率/下行波动率
│   └── size.py         # 市值因子
├── etf.py              # ETF因子（折溢价/AUM/跟踪误差）
├── cb.py               # 可转债因子（双低/纯债溢价率/YTM/转股溢价率）
└── macro.py            # 宏观因子（ERP/利率曲线/社融/CPI）
```

| 类/函数 | 输入 | 输出 | 说明 |
|----------|------|------|------|
| `Factor.evaluate(df, date)` | OHLCV + 财务数据 | Series of scores | 因子基类 |
| `PE.evaluate(df)` | 财务+价格 | PE倒数（E/P） | 低PE=高分 |
| `PB.evaluate(df)` | 财务+价格 | PB倒数（B/P） | 低PB=高分 |
| `Dividend.evaluate(df)` | 股息数据 | 股息率 | 高股息=高分 |
| `Momentum.evaluate(df, window=63)` | OHLCV | N日收益率 | 高动量=高分 |
| `Volatility.evaluate(df, window=63)` | OHLCV | 年化波动率 | 低波=高分 |
| `ROE.evaluate(df)` | 财务 | ROE | 高ROE=高分 |
| `CB.dual_low_price(df)` | 可转债数据 | 双低值=价格+溢价率×100 | 低值=高分 |
| `CB.ytm(df)` | 可转债数据 | 到期收益率 | 高YTM=高分 |
| `CB.conversion_premium(df)` | 可转债数据 | 转股溢价率 | 低溢价=高分 |
| `Macro.erp(index, bond)` | PE倒数+国债收益率 | 股债性价比 | >2%偏股 |
| `Macro.csi_yield_gap()` | 沪深300股息率-国债 | 股息率溢价 | 正值=偏股 |

**因子合成流程：**
```
原始数据 → 单因子计算 → 截面标准化(z-score) → 行业/市值中性化 → 等权/加权合成
```

| 类/方法 | 说明 |
|----------|------|
| `Strategy.rebalance(date, universe, data)` → `Signal` | 策略基类，返回调仓信号 |
| `Signal` | 数据类：`{symbol: target_pct}` 目标仓位百分比 |
| `ETF_Rotation(momentum_window=63, hold_n=2)` | 持有动量最强的N只ETF |
| `Industry_Rotation(momentum_window=63, hold_n=3)` | 行业ETF动量轮动 |

| `FED_Model(erp_high=0.02, erp_low=0.0)` | 股债性价比仓位管理 |
| `Commodity_Rotation(momentum_window=63, hold_n=1)` | 商品ETF动量轮动 |
| `Multi_Factor(factor_weights, hold_n=25)` | 多因子选股 |
| `Asset_Allocation(target_weights, rebalance_threshold=0.05)` | 大类资产配置+再平衡 |

**ETF轮动策略伪代码：**
```python
class ETF_Rotation(Strategy):
    def rebalance(self, date, universe, data):
        etfs = universe.get_etfs(categories=['WIDE'])  # 获取宽基ETF列表
        returns = {} 
        for etf in etfs:
            close = data.get_close(etf, date, lookback=self.window)
            returns[etf] = close[-1] / close[0] - 1
        sorted_etfs = sorted(returns, key=returns.get, reverse=True)
        # 持有动量最强的 hold_n 只
        weights = {etf: 1.0/self.hold_n for etf in sorted_etfs[:self.hold_n]}
        return Signal(weights)  # 剩余资金 = 货币ETF
```

### Module 5: `backtest/` — 回测引擎

**职责：按策略信号模拟交易，计算绩效指标**

```
src/quant/backtest/
├── __init__.py
├── engine.py           # 回测主引擎（事件驱动 or 向量化）
├── metrics.py          # 绩效指标计算
├── report.py           # 回测报告生成
└── benchmark.py        # 基准比较
```

| 类/函数 | 说明 |
|----------|------|
| `BacktestEngine.run(strategy, start, end, initial=1e6)` | 运行回测 |
| `BacktestEngine._simulate_trade(date, signal, prices)` | 模拟当日交易 |
| `BacktestEngine._deduct_cost(value, turnover)` | 扣除交易成本 |
| `Metrics.annual_return(nav_series)` | 年化收益率 |
| `Metrics.max_drawdown(nav_series)` | 最大回撤 |
| `Metrics.sharpe(nav_series, risk_free=0.02)` | 夏普比率 |
| `Metrics.calmar(nav_series)` | 卡玛比率(年化收益/最大回撤) |
| `Metrics.win_rate(nav_series)` | 胜率 |
| `Metrics.rolling_drawdown(nav_series, window=252)` | 滚动回撤 |
| `Report.generate(metrics, benchmark)` | Markdown回测报告 |

**回测参数配置：**
```python
BacktestConfig:
  initial_capital: 1_000_000      # 初始资金
  commission: 0.0003              # 佣金 万分之三
  stamp_duty: 0.0005              # 印花税 万分之五
  min_commission: 5               # 最低佣金 5元
  slippage: 0.001                 # 滑点 千分之一
  etf_commission: 0.0001          # ETF佣金 万分之一（免印花税）
  cb_commission: 0.0002           # 可转债佣金 万分之二（免印花税）
```

**回测流程：**
```
for each trading day:
    1. 策略生成调仓信号
    2. 计算目标仓位 vs 当前持仓 → 需要交易的标的
    3. 扣除交易成本（佣金+印花税+滑点）
    4. 更新持仓和净值
    5. 记录当日NAV

回测结束 → 计算绩效指标 → 生成报告
```

## 三、模块依赖关系

```
          monitor          ← 最上层
             │
      ┌──────┴──────┐
      │   portfolio  │     ← 组合层
      └──────┬──────┘
             │
      ┌──────┴──────┐
      │  backtest   │     ← 回测层
      └──────┬──────┘
             │
      ┌──────┴──────┐
      │ strategies  │     ← 策略层
      └──┬──────┬───┘
         │      │
    ┌────┴─┐ ┌──┴────┐
    │factors│ │universe│   ← 因子+标的管理
    └──┬───┘ └───┬───┘
       │         │
    ┌──┴─────────┴───┐
    │     data       │     ← 数据层（最底层）
    └────────────────┘
```

**依赖原则：上层依赖下层，下层不依赖上层。同层之间通过接口解耦。**

## 四、实施顺序

按依赖关系，从底往上：

| 阶段 | 模块 | 时间 | 原因 |
|------|------|------|------|
| **Phase 1** | `data/` | 先做 | 没有数据什么都没有 |
| **Phase 2** | `universe/` | 紧跟 | 需要知道能买什么 |
| **Phase 3** | `factors/` | 接着 | 因子是策略的原材料 |
| **Phase 4** | `strategies/` | 核心 | 策略是产出价值的模块 |
| **Phase 5** | `backtest/` | 验证 | 回测验证策略有效性 |
| **Phase 6** | `portfolio/` | 进阶 | 多策略整合 |
| **Phase 7** | `monitor/` | 最后 | 实盘时才需要 |

**MVP（最小可用产品）：Phase 1-4, 只做ETF轮动一个策略。**
做通 → 再加可转债 → 再加股债性价比 → 再加商品 → 最后整合。

## 五、关键接口约定

### 数据层 → 上层接口

```python
# 统一数据访问接口
data.get_close(symbol, date, lookback=252)     → np.ndarray  # 后复权收盘价
data.get_volume(symbol, date, lookback=252)    → np.ndarray
data.get_prices(symbols, date, lookback=252)   → pd.DataFrame
data.get_financial(symbol, field, date)         → float        # 最新财报数据
```

### 策略层 → 回测层接口

```python
@dataclass
class Signal:
    date: datetime
    weights: dict[str, float]   # symbol → target_pct
    metadata: dict              # 策略说明/调试信息

# 回测引擎调用
signal = strategy.rebalance(date, universe, data_provider)
# signal.weights = {"510300": 0.5, "510500": 0.5}  → 50%沪深300 + 50%中证500
```
