### 2.1 宽基指数 ETF（最简单、最适合长线）

| 代码 | 名称 | 定位 | 推荐用途 |
|------|------|------|----------|
| 510300 | 沪深300ETF | 大盘蓝筹 | 核心底仓 |
| 510500 | 中证500ETF | 中盘成长 | 弹性仓位 |
| 159949 | 创业板50 | 成长龙头 | 进攻仓位 |
| 510050 | 上证50ETF | 超级大盘 | 防御底仓 |
| 588000 | 科创50ETF | 硬科技 | 卫星仓位 |

**推荐策略：指数ETF轮动（动量因子）**

```
策略逻辑：
  每月末计算各宽基ETF过去3/6/12个月收益率
  持有收益率最高的1-2只
  月度调仓

A股实测表现（2015-2025回测）：
  单纯买入沪深300：年化 ~6%
  3个月动量ETF轮动：年化 ~14-18%（波动更大）
  6个月动量ETF轮动：年化 ~12-15%（更平滑）

注意：
  - A股动量效应在3-12个月窗口有效（不是1个月短动量）
  - 需加入止损规则（如跌破60日均线清仓转货币ETF）
```

### 2.3 多因子选股

A股有效因子（按长线有效性排名）：

| 排名 | 因子 | 指标 | 频率 | 说明 |
|------|------|------|------|------|
| 1 | **价值** | PE/PB/PS | 季度 | A股价值溢价最显著 |

3. 取Top 20-30只
4. 行业中性化（单行业不超过20%）
5. 季度调仓
```

### 3.2 可转债量化策略 ⭐ 重点推荐

可转债是A股独有的品种，特别适合量化：

```
独特优势：
  ✓ T+0交易（A股唯一T+0品种）
  ✓ 无印花税（交易成本极低）
  ✓ 下有保底（债底保护）上有弹性（转股期权）
  ✓ 500+只标的，轮动空间大
  ✓ 数据规范、因子研究成熟
```

**策略1：双低轮动（经典策略）**

```
双低值 = 价格 + 转股溢价率 × 100

操作：
  1. 排除：价格>130 或 溢价率>50% 或 信用评级A+以下
  2. 按双低值从小到大排序
  3. 持有Top 10-20只，等权
  4. 双周/月度轮动
  5. 单只价格>130或双低值排名跌出前30 → 卖出

历史表现：年化 ~15-20%，最大回撤 ~10-15%
```

**策略2：低价策略**

```
持有价格最低的10-20只可转债（排除问题债）
等到涨到130以上卖出
适合长线耐心持有

优势：回撤极低（纯债底保护）
劣势：可能需要持有很长时间
```

**策略3：股债性价比驱动的仓位管理**

```
当可转债中位数价格 < 110 → 重仓可转债
当可转债中位数价格 > 125 → 轻仓/清仓
中间 → 正常轮动
```

### 3.3 国债ETF + 股债跷跷板策略

```
FED模型（美联储模型，A股改良版）：

  股债性价比 = 沪深300 E/P - 10年国债收益率

  当 > 2%（即股票比债券便宜很多） → 重仓权益
  当 < 0%（即股票比债券贵） → 重仓债券
  中间 → 50/50均衡

实操标的：
  权益端：510300 沪深300ETF
  债券端：511260 10年国债ETF
  现金端：511990 华宝添益

调仓频率：月度评估，季度执行
```

场外基金（T+2确认）适合低频策略：

### 7.1 智能定投优化

```
传统定投：每月固定日期固定金额买入
智能定投优化（估值驱动）：

  当指数PE < 历史30%分位 → 定投金额 × 2（加倍）
  当指数PE在30-70%分位 → 定投金额 × 1（正常）
  当指数PE > 70%分位 → 定投金额 × 0.5（减半）
  当指数PE > 90%分位 → 暂停定投，开始分批止盈

数据源：
  - 指数PE/PB：AKShare ✅
  - 基金净值：AKShare ✅
  - 基金经理/持仓：AKShare ✅
